# Stepwise English

Платформа для изучения английского языка с уровня A1 до C2 и подготовки к Duolingo English Test (DET). Интерфейс на русском языке.

**Открыть сайт:** GitHub Pages этого репозитория (Settings → Pages).

## Возможности
- Уровни CEFR A1–C2, диагностический тест, итоговые экзамены уровней
- Vocabulary: карточки слов с IPA, русской подсказкой произношения и озвучкой; 8 режимов тренировки; интервальное повторение
- Grammar: 98 тем от A1 до C2 (20 авторских уроков)
- Reading, Listening, Writing, Speaking
- Тренажёры всех 13 типов заданий DET и пробный экзамен (Mock Test)
- Личный кабинет, журнал ошибок, личный словарь, админ-панель с импортом CSV/JSON

## Сборка
Исходники лежат в `src/`. Сборка в один файл `index.html`:
```
bash src/build.sh
```

## Ограничения версии на GitHub Pages
AI-проверка, разговорный тренажёр, голос Claude и облачная синхронизация работают только в версии на claude.ai. На GitHub Pages прогресс сохраняется в браузере (localStorage), озвучка идёт через голоса браузера, а проверка письма работает в базовом режиме.

Тренировочные задания — собственные материалы аналогичного формата. Платформа не связана с Duolingo.
